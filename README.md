# Wildberries Price Monitor

Python-парсер для сбора и мониторинга цен товаров на Wildberries. Проект собирает данные из поисковой выдачи, фильтрует и сортирует товары, сохраняет результаты в Excel и JSON, а также формирует отчёт об изменениях между запусками.

## Возможности

- Сбор данных о товарах из поисковой выдачи Wildberries.
- Настройка поискового запроса через командную строку.
- Фильтрация товаров по цене, рейтингу и количеству отзывов.
- Сортировка по цене, рейтингу и количеству отзывов.
- Экспорт результатов в Excel с оформлением и ссылками на товары.
- Сохранение истории запусков в JSON.
- Сравнение текущих результатов с предыдущей сохранённой историей.
- Формирование Excel-отчёта об изменениях цен, рейтингов и отзывов.
- Повторные попытки при временных ошибках HTTP-запросов.
- Ежедневный запуск по расписанию.

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/borispsychologi-cloud/freelance-parser.git
cd freelance-parser
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Использование

Запуск с поисковым запросом по умолчанию:

```bash
python wb_parser.py
```

Запуск с собственным запросом:

```bash
python wb_parser.py --query "кроссовки мужские"
```

Запуск с ежедневным расписанием:

```bash
python wb_parser.py --schedule
```

В режиме расписания парсер выполняет первый запуск сразу, затем ожидает следующего запуска по заданному времени. Время задаётся в настройке `RUN_TIME` в файле `wb_parser.py`.

## Результаты работы

В зависимости от полученных данных программа создаёт:

- Excel-файл со списком найденных товаров.
- JSON-файл с историей запуска в папке `wb_history`.
- Excel-отчёт об изменениях при наличии предыдущей истории.

Файлы результатов и журналы работы не предназначены для хранения в GitHub.

## Ограничения

- Структура поисковой выдачи Wildberries и доступность используемого API могут изменяться.
- Состав и количество найденных товаров зависят от поискового запроса и параметров выдачи.
- Корректность результатов зависит от доступности источника и структуры возвращаемых данных.
- Проект предназначен для учебных и демонстрационных целей.
